===============================================
🚀 直接部署 - 复制粘贴执行
===============================================

请打开终端，复制粘贴以下命令（会提示输入密码3次，都是 your_password）：

-------------------方法1: 使用一键脚本-------------------

./one-click-deploy.sh


-------------------方法2: 手动命令（更可靠）-------------------

# 1. 传输部署包（输入密码: your_password）
scp llm-chat-complete-fix.tar.gz ubuntu@your-server-ip:/opt/llm-chat-platform/

# 2. 传输脚本（输入密码: your_password）
scp deploy-on-server.sh ubuntu@your-server-ip:/opt/llm-chat-platform/

# 3. SSH登录并部署（输入密码: your_password）
ssh ubuntu@your-server-ip

# 然后在服务器上执行：
cd /opt/llm-chat-platform
chmod +x deploy-on-server.sh
./deploy-on-server.sh


-------------------方法3: 一次性命令（推荐）-------------------

复制整个命令块，粘贴到终端，按3次回车输入密码：

scp llm-chat-complete-fix.tar.gz ubuntu@your-server-ip:/opt/llm-chat-platform/ && \
scp deploy-on-server.sh ubuntu@your-server-ip:/opt/llm-chat-platform/ && \
ssh -t ubuntu@your-server-ip "cd /opt/llm-chat-platform && \
tar xzf llm-chat-complete-fix.tar.gz && \
docker compose -f docker-compose.final.yml build && \
docker compose -f docker-compose.final.yml down && \
docker compose -f docker-compose.final.yml up -d && \
echo '' && \
echo '✅ 部署完成！' && \
echo '' && \
echo '请清除浏览器缓存后访问: http://your-server-ip:3212' && \
docker compose -f docker-compose.final.yml ps"


===============================================
📝 密码提示
===============================================

所有密码提示都输入: your_password

===============================================
✅ 部署完成后
===============================================

1. 清除浏览器缓存 (Ctrl+Shift+R 或 Cmd+Shift+R)
2. 访问 http://your-server-ip:3212
3. 测试功能:
   - 上传 .docx 或 .xlsx 文件
   - 查看顶部只有一个栏
   - 对话历史中悬停显示删除按钮
